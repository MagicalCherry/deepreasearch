# 行业信息助手

本项目在已有行业信息助手系统的基础上，接手并改进深度研究 Agent，提升 AI 检索与多步研究的效果。

## 项目结构

- `docs/项目理解.md`：项目目标、验收方式和开发约束。
- `docs/课程协作约定.md`：贯穿课程的学习与协作方式。
- `src/`：后续实现的评测后端与研究 Agent。
- `runs/`：评测运行记录（不纳入 Git）。

## 开发约定

- 使用固定语料和 BM25 检索，按课程步骤迭代并用数据评测。
- 评测答案及证据文档编号仅供评测程序使用，不得进入 Agent 的提示词、工具结果或检索请求。
- 每个课程步骤完成后提交 Git，并按步骤打 tag。
