# S06 前后端接入

教案任务：先浏览成品四个评测标签及既有研究报告；写接口红灯测试；实现接口、SSE和断开取消；分类云端错误并在欠费时取消批量任务；前后端联调；收集原始测试输出、研究事件和停止日志交tutor验收。

用户确认本项目评测后端改为8001，保留占用8000的swxy_api及其他容器。

scripts/prepare_frontend.py将课程02-前端成品复制至frontend_runtime，排除.env及其变体、虚拟环境、依赖缓存和Git目录。副本用mas-s06-preview作为Compose项目名，评测nginx/Vite代理指向8001。副本及其数据配置被Git忽略，课程原件不修改。

frontend_runtime存放完整成品运行副本，包含原产品后端、前端、数据库初始化脚本和Docker配置。首次启动需下载镜像和构建，消耗网络与磁盘，不配置真实云模型Key，仅先看本地已有演示数据。

在Projects终端启动：docker compose --project-directory ./frontend_runtime -f ./frontend_runtime/docker-compose.yml -p mas-s06-preview up -d --build

浏览http://localhost:5183，演示账号dev / dev123456。原产品后台端口8020；评测后端随后使用8001。不要点击新建研究或立即采集，只浏览现有报告和评测示例。

阶段开始检查点来自S05提交6285d60及s05-complete标签。S06尚未完成验收。

## 接口与错误处理进度

- 已浏览成品页面，运行副本启动正常。
- app/api.py已实现健康检查、版本列表、研究SSE、断开取消；模型健康探测最多输出1个token，缓存60秒。
- app/llm.py增加LLMError四类错误，欠费不重试；审核只在提供截短回调时重试，超时和其他服务错误有限退避重试；取消直接传播。
- 运行器原先遇欠费仍启动排队题，离线测试明确复现。现改为在释放并发位置前设置停止标记并取消其他任务，保留成功记录和欠费原文，状态含stopped、reason=arrearage及pid。同编号续跑仍要求配置与代码提交一致。
- 欠费停批不等于美元预算硬上限；当前没有实现美元总预算强制截止。
