    ② Scout 内部 · 新流程加在哪里？

    “追踪搜索”与“阅读全文”有什么区别？

    原 Scout 的两层追踪是从分析结果里取后续检索词，再调用搜索和分析；不代表自动打开网页里的所有链接。v1.3把候选验证查询优先塞入既有追踪入口。

    v1.4才把 docs_to_read 接到 read_docs()：按已返回的docid读取正文，再提取带原文片段的事实。每篇最多8000 token，不保证完整长文全部读完。

    为什么会出现 0 搜索的 Scout？

    v1.2起，clean_query() 拒绝带未替换占位符的查询，例如 [Actor Name]。若一组初始查询全部被拒绝，子任务即使已发“开始”事件也可能0搜索；没有自动重生成查询的恢复机制。v1.4还会因重复查询或预算耗尽返回空结果。这些是不同原因。
