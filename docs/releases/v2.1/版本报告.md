# v2.1：S17搜／翻／读三工具

## 实现与验证

显式基于v1.9.1，保留引用纠错；增加snippet=passage、toolset=pi、search_depth=200、page_chars=1200、title_ranks=15。测试发现旧指纹会误删无数字英文事实，按学员确认仅本版启用fact_dedup=full_text。旧版本不变。相对v1.9/v2.0不是纯三工具消融，不将全部增益归因于工具。

PiTools缓存深排200条，展示5片段+15标题；翻页最多20条，不增加实际搜索次数；按80词行读正文，每次8000 token封顶。每任务最多12次工具调用，整题50次搜索/8篇唯一文档共享，正文内部缓存不直接交给模型，引用纠错仅读实际曝光片段。初始及补搜均走三工具入口。尚存在补搜零行动、候选漂移、负面搜索总结作为事实及最终强猜问题，另行处理，不混入冻结实验。

学员最终全量测试原文：237 passed in 2.14s。实现c10bdfb，dev100研究来源7384628c9badf37afb9a93106e452c80bf0431e7；smoke20复用20题，dev100仅新增80题及判分，保留来源配置。后续提交仅归档，无研究代码改动。

## 如何读工具统计

100题实际搜索2387次；翻页122次，63/100题使用翻页；分块阅读652次、按题去重340篇，其中80篇从该Scout仅标题列表可见状态直接打开。每题分别23.87搜、1.22翻页、6.52读块、3.4篇全文、0.8篇标题直读。读篇约为v2.0的2.19倍；不能将6.52读块当成不同全文篇数，也不能把缓存200条当成召回。

学员复盘原话：“每次翻页都会重新搜索，所以要少翻页”。已纠正：翻页读取缓存，不重新检索；标题足以直接挑篇读，正文分块又可能多次调用，所以读文次数多于翻页。没有替学员声称已经理解。
