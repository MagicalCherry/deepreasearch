## 复现与来源

- 模型与判分均为OpenRouter qwen/qwen3.7-flash，按学员费用授权替代任务书指定模型；不是qwen3.8-flash同条件成绩。
- 每组复用同一版本既有smoke20的20份成功结果及判分，补跑其余80题。各导入题实际并发和提交见本地runs下的source_config.json、resume_provenance.json；部分题最初使用并发2，不能把全组当作受控的并发8延迟实验。
- S4补跑使用原冻结工作树，避免开发中的观测功能和S10变化污染基线。超时、连接失败和额度不足后通过原命令续跑，仅保留最新成功结果，运行错误最终为0；失败尝试费用可能不在成功结果token统计中。
- 原始results.jsonl、judged.jsonl保留在学员本机runs/，Git忽略，不发布题集标准答案、证据标注、密钥或.env。此目录只发布汇总与运行配置。
- 在项目根目录填写本地.env.openrouter（不要提交），通过LLM_PROVIDER=openrouter、LLM_MODEL_PROFILE=economy选择模型；按README/课程材料准备只读题集、固定语料检索服务，再运行app.cli。课程材料、题集与语料不在本仓库，需另行取得；仅克隆仓库不构成完整数据环境。
