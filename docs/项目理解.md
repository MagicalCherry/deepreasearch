# 项目理解

## 要做什么

在已有行业信息助手的基础上，接手并逐步改进深度研究 Agent，让它更善于搜索资料、核对信息并回答需要多步研究的问题。

## 怎么算做完

后端要能接入现有前端，支持研究过程展示、评测运行、题集管理和运行对照等功能，并通过任务书规定的功能验收。

## 怎么算做好

用固定 dev100 开发集评测每个版本，目标是准确率至少 75%、证据召回至少 70%、校准误差不超过 10、运行错误不超过 2 题、平均耗时不超过 300 秒、平均检索次数不超过 50 次。改进要能从运行记录和版本对照中追溯。

## 几条规矩

- 评测答案和证据文档编号只供评测程序使用，不能进入 Agent 的提示词、工具结果或检索请求。
- 检索使用课程指定的固定语料和 BM25 服务，不把语料改成向量检索。
- 每次改进都通过评测数据判断效果，并保存代码版本和运行配置。
- 不读取、打印或提交 `.env` 文件及密钥。
