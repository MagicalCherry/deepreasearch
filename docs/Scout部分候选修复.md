# v2.3.4：部分候选与自动翻页限额

v2.3.3 smoke20原始结果为14/20、召回67.97、校准11.35、运行错误0、平均185.1秒。较v2.3改善486、退步422/1025/297，配对p=0.625，不认定稳定退步或改善。三题初始候选更新为0，旧日志不足以区分缺失或解析错误；自动转翻页分别22/18/16次，未证明其因果影响。

用户授权先修复。失败反馈原文：cannot import name 'inspect_progress'；1 error in 0.12s。实现后由学员验证，不自动运行测试或模型。

新版本只增加candidate_progress_v2=True及max_auto_reviews=2。每个Scout工具上下文自动转翻页最多2次，额度用完仍可显式翻页、读文或执行不同的新查询；近似重复仍可能被拒绝，日志保留原因。不会自动放行近似查询或承诺彻底消除空转。600秒、模型、原搜索和工具尝试上限不变。

新版候选协议分partial_candidates与answer_candidates，二者仍是hypothesis。inspect_progress区分missing/invalid_json/invalid_schema/empty/valid，保存原始进度块及解析原因，供判断模型未输出还是格式失配；不增加模型纠错调用、不从金标补候选。兼容合法旧数组，但旧版本继续原解析路径。

新版合并不因新子任务未重读旧来源，就以unresolved覆盖已保存的supported/refuted；新轮核对记录仍进入history。已观察来源的新支持/反驳可以更新当前视图，这只验证来源编号，不等于语义正确。pending按精确条件文字保留，只有本次有有效支持/反驳的同条件才移除旧待查项；不以空数组直接清空。仍需模型主动报告部分候选，未实现可靠实体自动提取或强制候选调度，不宣称已完全解决候选遗漏。

所有补丁独立注册，旧版结果和研究行为不改。待专项和全量通过后再决定新评测范围，不能用单题诊断代替整体改善证据。
