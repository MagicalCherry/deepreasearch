# 外部题集目录

设置进程环境变量 `DATASET_DIR` 后，研究运行器与 OpenRouter 判分脚本都从该目录读取 `<题集名>.jsonl`。支持内置名称及自定义名称；只允许字母、数字、下划线、短横线，不接受文件路径作为题集名。相对目录以 Projects 根目录为基准。文件缺失直接报错，不回退到其他目录。

不设置或设置为空白时保留原行为：研究端内置题集从课程目录读取、自定义题集从上传目录读取；判分端使用原课程加载器。前端上传、删除仍仅操作原上传目录，不写入外部目录。此入口不负责让外部题集自动出现在前端题集列表中。

PowerShell 设置示例（替换成验收方自己的目录）：

```powershell
$env:DATASET_DIR = 'D:\evaluation\datasets'
```

研究命令示例（会调用模型并产生费用，此处仅作交付说明）：

```powershell
uv run python -X utf8 -m app.cli run --dataset custom --version v2.3 --run-id final-custom --concurrency 8
```

沿用当前已经配置的模型平台与凭证；本项不切换模型。题集每行一个JSON对象，研究端仅取 `query_id` 和 `query`；`answer`、`gold_docids`、`evidence_docids` 留在离线评测边界。判分命令须继承相同的 `DATASET_DIR`。

```powershell
uv run python -X utf8 scripts/judge_openrouter.py --run runs/final-custom --dataset custom --execute
```

清除当前终端的覆盖：

```powershell
Remove-Item Env:DATASET_DIR -ErrorAction SilentlyContinue
```

修改后需重启已启动的后端进程。新增离线测试使用临时目录与虚构题目，不访问模型或检索服务；等待学员手动执行验证。
