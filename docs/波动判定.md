## 多重比较与限制

上述8组dev100比较同时观察，若作为同一探索比较族采用Bonferroni，参考门槛0.05/8=0.00625，仅v1.9→v2.1仍低于该门槛；v2.0→v2.1不再通过。该比较族为事后整理且存在重叠，不能冒充预注册验证，也不涵盖此前所有选择与调参的多重性。若把6组smoke也计入14组，门槛约0.00357，仍只有v1.9→v2.1通过。

精确检验条件于翻转题数，在“两个方向同等可能”的零假设下计算尾概率；p不是改动无效的概率。p大不证明等效、无损或错误根因相同。不同版本存在多项机制组合、共享开发集、失败重试与时间环境差异，不能将统计结果视为单一改动因果或样本外保证。

## 本阶段报告采用的判定规则

1. 先核对相同题集、判分口径和配置差异，保留错误及全部原始成绩；展示净增和改善/退步两侧，而非只报准确率。
2. 开发集准确率上升但配对检验未达门槛，只称“本次观察到提升，尚未证实稳定改善”。机制合理可作为保留实验方案的理由，不能替代统计证据。
3. 单次p<0.05称“有初步配对证据”，报告效应大小和多重比较；探索比较应采用明确的校正或后续独立确认。重复试到显著不能作为验证。
4. 同配置重复方向、机制记录及独立数据验证共同支持时，才升级为“稳定改善”；当前开发集再好也不称已证明泛化。样本外730由验收方检验，开发方不读取。
5. 性能、校准与准确率分别评价。更快不等于质量无损；置信度规则不能认领重新研究带来的正确题增量；校准比较优先用同批固定答案的离线重标。
